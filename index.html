Playlist privacy: URL loading happens in your browser. Some playlist hosts block browser requests (CORS); in that case, download the playlist and upload the file instead. A playlist loaded by a visitor is not automatically published to every other visitor.
To publish channels for everyone: edit channels.m3u in your GitHub repository and commit your authorized channel list. Local uploads and single-stream additions are stored only in this browser.

This site is a client-side player and playlist reader; it does not host, relay, or guarantee the availability of any stream. Playback depends on the stream provider, format, browser support, CORS settings, and internet connection. HLS.js is loaded from jsDelivr. Use only streams you have permission to distribute.
